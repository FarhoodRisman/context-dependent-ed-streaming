# One Policy Does Not Fit All

*Matching Patient Streaming Policies to Emergency Department Types* (target: IEEE Transactions on Engineering Management)

Start with `notes/PROJECT_BRIEF.md`; decisions are logged in `notes/DECISIONS.md`.

| Folder | Contents |
|---|---|
| `paper/` | LaTeX manuscript (IEEE TEM template in `template/`), `ed_library.bib`, figures |
| `sim/` | Python simulation package, tests, ED-type configuration files |
| `experiments/` | Experiment scripts and results |
| `lit/` | Literature notes and extracted data (e.g. pathway table from Rismanchian et al. 2023) |
| `notes/` | Project brief and decisions log |
| `from_IISE/` | Reference copies from the IISE paper (code, aggregate results, manuscript, STRESS checklist). No patient-level data. |
| `bib/` | Copies of the two source .bib files; the master library is `../ED Reference Library/ed_library.bib` |
