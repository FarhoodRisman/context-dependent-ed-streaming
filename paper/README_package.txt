One Policy Does Not Fit All: Matching Patient Streaming Policies to Emergency Department Types
LaTeX package (IEEE Transactions on Engineering Management)

Files
  main_review.tex / .pdf   Submission version: anonymised, single column, double spaced, 12 pt
                           (TEM double-blind review, 38-page limit).
  main.tex / .pdf          Two-column IEEE journal layout with author names (for co-authors).
  preamble.tex             Shared packages; reads numbers.tex.
  sections/                Manuscript text (shared by both versions).
  numbers.tex, tables/, figures/
                           Generated by experiments/scripts/make_outputs.py from the raw
                           simulation results. Do not edit by hand: re-run the pipeline.
  outputs_provenance.json  Code commit, configuration hash and run settings of every
                           results file used.
  ed_library.bib           Bibliography (copy of the shared ED Reference Library).
  IEEEtran.cls             IEEE class file.
  supplement/              STRESS-DES checklist (tex, pdf) and supplementary CSV tables
                           (all KPIs by ED type and policy, regret, decision guide, ...).

Compiling
  pdflatex + bibtex (or latexmk -pdf) with the IEEEtran bundle (IEEEtranN.bst), as on
  Overleaf. If IEEEtranN.bst is not installed, compile with
      latexmk -pdf -usepretex='\def\localbst{1}' main_review.tex
  which uses natbib's unsrtnat style instead (the enclosed PDFs were built this way).
